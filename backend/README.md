# OpenSync

One registry for your AI coding setup. OpenSync keeps MCP servers, skills,
rules/instructions, slash commands and subagents in a local SQLite registry
and syncs them to the native config formats of Claude Code, Claude Desktop,
Codex, GitHub Copilot, Cursor, Devin, Gemini CLI, OpenCode, Antigravity and
Warp — with drift detection, diff previews and one-click import of what's
already on your machine.

```bash
uvx open-sync          # start the server and open the web UI
opensync --help        # after: uv tool install open-sync
```

Full documentation: https://github.com/brandon-braner/open_sync
